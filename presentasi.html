02 • LATAR BELAKANG

Latar Belakang & Solusi

Mengapa Dapur Nusa dibangun untuk membantu koki rumahan dan pecinta kuliner.

⚠️

Masalah

  • Resep tradisional takarannya sering tidak baku ("secukupnya").
  • Sulit menghitung ulang porsi jika ingin masak untuk porsi besar.
  • Pencatatan belanja bahan masakan masih serba manual.
🐌

Kendala Web Lain

  • Banyak website resep terlalu berat karena library JS berlebih.
  • Seringkali lambat dibuka di ponsel dengan sinyal standar.
  • Tampilan penuh iklan yang mengganggu langkah memasak.
💡

Solusi Dapur Nusa

  • Katalog resep terstruktur dengan takaran dan langkah jelas.
  • Kalkulator Porsi Dinamis otomatis seketika.
  • Daftar Belanja Cerdas langsung dari bahan resep.

03 • ARSITEKTUR TEKNOLOGI

Stack Teknologi: DATH Stack

Kombinasi 4 pilar teknologi yang menghasilkan website cepat, modern, dan ringan.

BACKEND & KEAMANAN

Django 5.2 (Python)

Menyediakan database ORM yang kuat, sistem user & hak akses, serta proteksi keamanan bawaan (CSRF, XSS, SQL Injection).

INTERAKSI TANPA RELOAD

HTMX 2.x

Memungkinkan pencarian langsung (*live search*), filter kategori, dan simpan favorit secara instan tanpa perlu memuat ulang seluruh halaman.

REAKTIVITAS MIKRO

Alpine.js 3.x

Mengatur slider porsi piring real-time, menu navigasi mobile, dan jendela popup (modal) langsung di browser tanpa kompilasi.

TAMPILAN MODERN

Tailwind CSS (Material 3)

Desain bersih dan konsisten berbasis Material Design 3 dengan palet warna hangat khas rempah nusantara yang ramah pengguna.

05 • TATA KELOLA KONTEN

Moderasi Resep & Dashboard Admin

Menjaga standar kualitas resep komunitas sebelum dipublikasikan.

🚦 Alur Moderasi (Status Workflow)

  • Status PENDING: Resep yang baru dibuat pengguna tidak langsung tampil ke publik.
  • Setujui (Approve): Admin memverifikasi dan resep resmi berstatus PUBLISHED.
  • Tolak (Reject): Admin menolak dengan wajib menyertakan alasan penolakan yang jelas.
  • Transparansi Penulis: Penulis tetap bisa melihat resep miliknya dan membaca catatan perbaikan.

📊 Dashboard Administrator

  • Ringkasan metrik total resep aktif, resep pending, dan jumlah pengguna.
  • Aksi cepat moderasi langsung dari tabel review.
  • Pengelolaan kategori masakan nusantara dan tag pencarian.
  • Semua aksi moderasi dilindungi metode aman POST + token CSRF.

06 • DATABASE & MODEL DATA

Struktur Database Relasional

Desain tabel yang rapi menjamin data resep tersimpan terstruktur dan konsisten.

Model / Tabel Fungsi Utama Relasi Database
User & UserProfile Akun pengguna & peran (*Role Admin / Pengguna Biasa*). 1-to-1 via Django Signals
Category & Tag Klasifikasi daerah nusantara dan ciri khas masakan. Many-to-Many ke Recipe
Recipe (Utama) Judul, slug unik, waktu persiapan, porsi, status publikasi. Foreign Key ke User & Category
Ingredient & Step Daftar bahan (dengan takaran angka) dan urutan langkah masak. Foreign Key ke Recipe (Cascade)
ShoppingList Daftar belanja bahan milik pengguna dengan checklist centang. Foreign Key ke User
Favorite Penyimpanan resep yang disukai pengguna. Unique Together (User, Recipe)
